## ⚡ Quick Steps to Publish on Upwork

1. Open your Upwork Profile and click **"Add a new portfolio project"** (or edit an existing one).
2. Open [`UPWORK_PROJECT_DETAILS.md`](./UPWORK_PROJECT_DETAILS.md) and copy:
   - **Project title**: `Leitner Learning Platform - Offline-First Flutter & .NET 8 Mobile App`
   - **Your role**: `Lead Full-Stack & Mobile Architect (Flutter, .NET 8, PostgreSQL, React, SQLite, Docker)`
   - **Project description**: Copy the verified 589-character description snippet.
   - **Skills and deliverables**: Select skill tags (`Flutter`, `Dart`, `.NET Core`, `Clean Architecture`, `SQLite`, `PostgreSQL`, `React`, `Docker`, etc.).
3. Click the **Image icon** in the media section and upload `01_cover_thumbnail.png` as the cover image, followed by the presentation mockups and live screenshots.
4. Click **Publish**!
