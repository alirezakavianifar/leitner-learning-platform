### ۳. توضیحات پروژه (Project Description)

> **متن آماده پیشنهادی (انگلیسی - با رعایت محدودیت ۶۰۰ کاراکتر Upwork):**
>
> ```text
> Architected & engineered an enterprise-grade, offline-first Leitner flashcard learning platform with Flutter mobile app, .NET 8 backend, and React admin console.
>
> Key Deliverables & Tech Highlights:
> • Cross-platform Flutter (iOS & Android) with Feature-Based Clean Architecture & BLoC
> • Offline-first SQLite engine with encrypted card content & secure media storage
> • Robust .NET 8 Web API, PostgreSQL 16, Redis & tokenized JWT authentication
> • Dynamic failover network resilience, remote config & anti-screenshot security
> • Pluggable React Admin Suite for courses, live analytics & payment gateways
> ```

> **متن آماده پیشنهادی (فارسی):**
>
> ```text
> طراحی و پیاده‌سازی پلتفرم جامع و سازمانی جعبه لایتنر و یادگیری فاصله‌دار (Spaced Repetition) با معماری آفلاین-محور، اپلیکیشن موبایل فلاتر، وب‌سرویس دات‌نت ۸ و پنل مدیریت ماژولار ری‌اکت.
>
> دستاوردها و ویژگی‌های کلیدی فنی:
> • اپلیکیشن کراس‌پلتفرم فلاتر (iOS و اندروید) با Clean Architecture ماژولار و مدیریت وضعیت BLoC
> • موتور آفلاین مبتنی بر دیتابیس SQLite رمزنگاری‌شده محلی به همراه استریم امن صوت و تصویر
> • وب‌سرویس قدرتمند دات‌نت ۸ (.NET 8 LTS) با پایگاه داده PostgreSQL 16 و کشینگ ردیس (Redis)
> • سیستم بازیابی خودکار اتصال و تغییر پویای سرور (Dynamic Network Failover) و سوئیچ ضد اسکرین‌شات
> • پنل مدیریت واکنش‌گرا (React/TypeScript) جهت مدیریت دوره‌ها، لاگ‌های سیستمی و درگاه‌های پرداخت
> ```

### ۵. چکیده فنی پروژه

- **معماری کلاینت:** Feature-Based Clean Architecture همراه با BLoC، تزریق وابستگی (DI) و الگوی Repository
- **پشته فرانت‌اند موبایل:** Flutter 3.22+ LTS, Dart, SQLite Encrypted
- **پشته بک‌اند:** .NET 8 LTS (C# Web API), PostgreSQL 16, Redis 7, Hangfire, Docker
- **پنل مدیریت:** React 18/19, TypeScript, Vite, Tailwind CSS
- **امنیت محتوا:** رمزنگاری محلی دیتابیس با AES-256، بسته‌بندی دوره‌ها با ابزار پایتون، حفاظت ضد اسکرین‌شات پویای `FLAG_SECURE`
